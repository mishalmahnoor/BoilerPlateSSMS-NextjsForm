### Student registration Portal Platform
This is the official repository to store the boiler plate frontend code for simple forms that connect to SSMS.
The Frontend is made using 
Next.js, Node.js, ShadcnUI and Backend is in T-SQL leveraging SSMS.
There are three DB tables:
<ol>
  <li>
    Students
  </li>
  <li>Courses</li>
  <li>Registrations</li>
</ol>

<h5>Shadcn Commands:</h5>
npx shadcn@latest init -d
npx shadcn@latest add button input label card table tabs sonner -y
