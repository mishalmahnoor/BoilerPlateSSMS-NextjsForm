### Student registration Portal Platform
This is the official repository to store the boiler plate frontend code for simple forms that connect to SSMS.
The Frontend is made using 
Next.js, Node.js, ShadcnUI and Backend is in T-SQL leveraging SSMS.
There are three DB tables:
<ol>
  <li>
    Students
  </li>
  <li>Courses</li>
  <li>Registrations</li>
</ol>

<h5>Shadcn Commands:</h5>

```
npm install tailwindcss @tailwindcss/postcss postcss

```

<h5>SQL package:</h5>

```
npm install mssql
```

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.
